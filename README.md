# weight-converter
 (kgs to pounds/ pounds to kgs)

 programa simples em C feito para converter peso entre quilogramas e libras, feito via terminal.
 funcionalidade do programa:
 - conversão de quilogramas para libras
 - conversão de libras para quilogramas
 - interface muito simples

 - certificar ter gcc instalado
 - biblioteca ultilizada : <stdio.h>

 - formula = 1kg = 2.20462 lb
 - kg → lb: libras = quilogramas * 2.20462
   lb → kg: quilogramas = libras / 2.20462

   este projeto é de uso livre para fins de estudo e prática :P
